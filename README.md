# Cozy Dental : By Dr. Patani — Website

Redesigned, animated one-page marketing site for the dental clinic at **drpatanidental.co.in**
(Cozy Dental : By Dr. Patani, near Vinay Nagar Police Station, Wadala–Pathardi Road, Nashik).

## Run locally

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

## Structure

- `index.html` — full one-page site (hero, stats, services, about, doctor, gallery, Google reviews, map, contact, footer)
- `assets/css/styles.css` — design system, gradients, animations
- `assets/js/main.js` — interactions & lazy loading
- `assets/img/` — clinic photos, doctor photo, favicon
- `SITE-NOTES.md` — what changed, image replacement guide & deploy steps

Stack: plain HTML + CSS + vanilla JS (no build step) — upload anywhere as-is.
